
# SchoolFeeLedger

A School Fee Management System designed to simplify and organize school fee operations.

## Project Overview

SchoolFeeLedger aims to provide a centralized platform for managing students, classes, monthly fee vouchers, payments, receipts, and fee records.

## Technology Stack

- **Frontend:** React.js with Vite
- **Backend:** Node.js and Express.js
- **Database:** Supabase PostgreSQL
- **Version Control:** Git and GitHub
- **Containerization:** Docker

## Planned Features

- Student management
- Class and section management
- Monthly fee voucher generation
- Fee payment recording
- Payment receipts
- Outstanding fee tracking
- Fee reports and summaries
